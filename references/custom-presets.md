# 命名自定义团队方案

## 指令与范围

- “将当前团队保存为自定义方案《名称》”：读取当前明确配置，持久保存，告知名称与版本。若没有已配置团队，先引导配置，不编造当前成员。
- “列出我的自定义团队方案”：读取持久目录，显示名称、成员模型组合、派活方式与版本。
- “使用自定义方案《名称》”：读取并核对方案，生成新任务团队配置，展示分工并等待“开始”。可附“打开对话内配置”或“打开浏览器配置”选择编辑入口。
- “更新自定义方案《名称》”：展示差异并按用户明确的更新范围保存到同一方案身份；如用户已明确给出全部改动，直接更新，无需再问同一件事。

默认可跨项目复用。保存角色、模型、推理强度、派活方式、最大并发、成员依赖和建议修改范围；不保存实际任务文本、项目身份、材料路径、总体目标、Agent进程ID、升级重试次数、运行状态或验收结果。页面的“修改范围”可包含建议路径，但不是对新项目写入的授权，启用时必须核对。用户需要继续旧任务时使用项目交接，不把加载方案当恢复任务。

方案格式为 schema_version=1、kind=agent_team_preset、preset_id、name、preset_version、updated_at、assignment、start_mode=wait_for_start、max_concurrency、members。单模型自定义也允许；不得称其为内置混合预设。配置只保存用户明确选择，不因加载自动更换不可用模型或升级强度。

## 真正持久保存

对话内页面的“保存方案”通过宿主支持的提交接口直接发送保存请求，无需复制粘贴；接口不可用或离线浏览器页才提供手动导入回退。收到明确保存请求后，在本轮完成持久保存，不只返回提示词或暂存在浏览器。页面提交不等于已持久保存，以主 Agent 的保存结果为准。未选择具体方案的功能开发阶段不凭空创建个人方案。

ChatGPT Work 使用 Library skill：以精确标题 `agent-team-custom-presets.json` 查找个人方案目录。首次确实未找到时创建 schema_version=1、presets=[] 的目录文件；已有则读取并保留同一文件身份和版本，修改后使用条件替换。不要把用户方案存入本 Skill 目录，也不依赖页面 localStorage。

本地编码环境使用用户指定的持久目录；未指定时采用 `~/.codex/agent-team/custom-presets.json`，说明所在位置。项目仅用方案可放入项目的 agent-team 目录，由用户明确指定。不同设备/环境的目录不会天然同步；需要带入目录或导出方案JSON，不能声称所有Agent共享个人方案。

复用 `scripts/manage_presets.py` 管理已获得的本地目录文件：

```text
python3 <skill-root>/scripts/manage_presets.py --store <实际目录JSON路径> save --input <配置JSON路径> --name <方案名称>
python3 <skill-root>/scripts/manage_presets.py --store <实际目录JSON路径> list
python3 <skill-root>/scripts/manage_presets.py --store <实际目录JSON路径> get --name <方案名称>
```

名称作为参数安全传入，不拼接成文件路径。同名（忽略大小写和首尾空白）不静默覆盖。未明确要求更新时先展示差异，用户决定改名或替换；替换使用 `--replace --expected-version <真实当前方案版本>`。更新保留preset_id并递增版本。目录冲突时读取新版本并重新合并，不去掉版本保护；不要强删仍被占用的锁。脚本原子替换和本地锁只保护本地目录，远程写回仍需 Library 版本检查。

本地脚本返回成功不等于远程保存成功。远程写回成功后才能称“已保存，下次可用”；失败时保留导出副本并说明无法确认持久保存，不让页面列表把失败项冒充已保存。

## 下次加载与两版联动

每次打开配置页面，读取用户方案目录并将 presets 数组注入 renderer 的 `custom_presets`。找到多个同名目录时先消歧；读取失败时说明原因，不把失败当成空目录。上下文注入仅包含已成功保存的方案，不能包含临时保存请求。

用户已明确选择方案时，将其成员配置和当前环境能力一起加载；显示名称与版本。“我的自定义方案”下拉显示可加载项，修改后可另存名称。加载不启动成员。生成新项目配置时只引用 custom_preset 的身份、名称、版本，团队成员依赖随实际M编号映射，保留当前项目已填总体目标和材料。新方案不能覆盖原任务历史。

加载旧模型仍需检查当前模型/强度/并发能力，标出不支持项等待选择；不得静默降级或增加权限。按长期项目规则保存新分工与验收要求，等待开始。首次应用保存方案不是执行中的自主强度升级；用方案修改正在执行的任务仍受升级及范围变更规则约束。

同一个已保存方案在对话内和浏览器入口应得到相同配置语义。浏览器导出方案JSON可离线保留，重新粘贴到任一版本的恢复输入框可加载，但文件下载不等于主Agent已登记个人目录。页面读取按钮仅加载草稿，真正的方案保存和更新由主Agent完成。
